Prise en main de TenantPulse
Guide rapide de l'outil de diagnostic Microsoft 365. Tout reste dans votre navigateur.
1 Lancer une analyse

Saisissez un domaine (ex. contoso.com) dans le champ en haut de la colonne de gauche, puis :

  • Tenant ID (analyse rapide) : récupère le Tenant ID Microsoft 365 et les enregistrements DNS de base. Astuce : appuyez sur Entrée dans le champ pour la lancer.
  • Analyse (analyse complète) : ajoute le WHOIS du domaine et un audit de sécurité DNS (SPF, DKIM, DMARC, DNSSEC, MTA-STS, BIMI) avec un score.

Le résultat affiche le Tenant ID, un indice de confiance (cliquez sur le « i » à côté du score pour le détail) et un bouton pour copier le Tenant ID.

2 Accès rapide aux centres d'administration

Sous un tenant détecté, des boutons ouvrent directement les portails du client : Partner Center, Entra ID, M365 Admin, Exchange, Intune, Teams, SharePoint, Azure, Defender. Un clic les ouvre dans un nouvel onglet.

Astuce Edge Clic droit sur un de ces boutons → « Ouvrir le lien en tant que » → choisissez un autre profil Edge. Vous ouvrez ainsi le centre d'administration du client directement dans le profil Edge dédié à ce client.
3 Copier le rapport

Après une analyse, le bouton « Copier le rapport » copie un résumé texte (tenant, sécurité, services détectés) prêt à coller dans un ticket ou un e-mail.

4 Badges & classification des tenants

Sur la fiche d'un tenant validé, le bouton + permet de proposer une classification :

  • Balises standard : Direct, Indirect, GDAP actif, ou des balises personnalisées.
  • Votre proposition est validée par un modérateur avant d'apparaître pour toute l'équipe.
  • Vous pouvez aussi demander le retrait d'un badge existant.

Les badges sont partagés entre utilisateurs autorisés afin de classer votre portefeuille de clients.

5 Annuaire des tenants

Le bouton « Annuaire des tenants » (en haut à droite) ouvre le répertoire partagé des tenants déjà classés. Vous y retrouvez les clients référencés et leur classification, et pouvez copier leur domaine ou leur Tenant ID. Il se remplit automatiquement à partir des classifications validées.

6 Historique des Tenant ID (optionnel)

Désactivé par défaut. Pour le conserver d'une analyse à l'autre :

  • Activer : (interrupteur).
  • Régler la conservation : : nombre maximum de tenants et durée de conservation.
  • Nettoyage automatique : les entrées trop anciennes sont purgées à l'ouverture de l'app, à chaque analyse enregistrée, et quand vous changez la durée. Rien n'est nettoyé tant que l'application est fermée.

L'indicateur de cache dans la barre du haut montre l'état (actif, vide, désactivé, inactif). Vous consultez et effacez l'historique via le bloc « Historique des Tenant ID » dans la colonne de gauche.

7 Personnaliser vos raccourcis (Profils)

Le bouton Profils (en haut à droite) → onglet TenantPulse → section Raccourcis vous laisse :

  • activer / désactiver les boutons d'accès aux centres d'administration ;
  • les réordonner par glisser-déposer (Partner Center reste épinglé en tête).

L'onglet Diagnostic Messagerie personnalise aussi cette sous-application. Cliquez sur Enregistrer pour conserver vos choix.

8 Mode clair / sombre

TenantPulse suit automatiquement le thème clair ou sombre de votre système (Windows / Edge). Vous pouvez aussi le basculer manuellement via .

9 Vos données restent locales
  • Les analyses partent directement de votre navigateur vers les APIs officielles (Microsoft, Google DNS, RDAP), sans proxy ni serveur intermédiaire.
  • L'historique (optionnel) reste dans le localStorage de votre navigateur.
  • Pour inspecter ou tout vider : .
  • Seules les classifications (badges de l'annuaire) sont partagées en ligne pour être visibles par l'équipe.
10 Signaler un bug

Le lien « Report Bug(s) » en haut à gauche ouvre un e-mail pré-rempli pour signaler un problème.
