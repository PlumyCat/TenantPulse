Attention i
L'historique est stocké localement dans le localStorage de votre navigateur. Aucune donnée n'est transmise à un serveur.

Nettoyage automatique : les entrées dont l'âge dépasse la durée de conservation sont supprimées dans ces 3 cas :
  • à l'ouverture de TenantPulse ;
  • à chaque nouvelle analyse sauvegardée dans le cache ;
  • quand vous modifiez la durée de conservation ci-dessus.
Aucun nettoyage ne s'effectue tant que TenantPulse est fermé.

Si la durée est réglée sur « Illimité », aucune purge n'est effectuée (seule la limite du nombre max s'applique).
